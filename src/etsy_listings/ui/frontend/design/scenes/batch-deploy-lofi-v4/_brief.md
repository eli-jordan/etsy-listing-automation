# Batch deployment hi-fi — the agreed all-listings review path rendered with the app's real visual system and components.

Mode: Operate.

The seller starts from Listings, previews pending names by hovering Deploy
changes, then opens one plan across all listings. A dedicated planning state
covers the slow live-state fetch before the grouped review appears. The top of
the page uses the same compact step-strip language as individual deploy, showing
each stage's count and the listing currently running it. Clicking a listing opens
a bottom drawer with its stages and side-by-side comparison. Fake apply progress
advances the stage totals and finishes inline.

The live frames share the production shell, status tags, deploy step strip and
before/after comparison. Data and run progress remain in-memory fixtures.

Out of scope: API wiring and changing the existing per-listing deploy flow.
