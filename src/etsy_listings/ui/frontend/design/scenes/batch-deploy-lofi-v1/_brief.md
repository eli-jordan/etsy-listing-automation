# Batch deployment wireframes — snapshot before consolidating the comment explorations into one interactive flow.

Mode: Operate.

The seller starts from Listings, waits while the whole workspace is planned,
reviews grouped adds, updates and removals, expands a listing only for evidence,
then sees every outcome on that same review page after apply.

Out of scope: visual polish, API wiring, and changing the existing per-listing deploy flow.
