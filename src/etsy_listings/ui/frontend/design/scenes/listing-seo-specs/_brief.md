# Listing SEO assistance - a laptop-first review flow for seller-approved AI copy and description sources.

- Audience: a print-on-demand seller editing one Etsy listing at a desktop/laptop.
- Job: generate ranked choices and deliberately select an SEO title, tags, and description lead.
- Mode: Operate.
- Flow: readiness → generating → proposal review → accept or regenerate → edit saved fields normally.
- Content: listing facts, design, brief, garment data, `common-copy/` description bodies, and browser-local proposals.
- Out: prompt editing, mobile/tablet work, external SEO statistics, and publication itself.
