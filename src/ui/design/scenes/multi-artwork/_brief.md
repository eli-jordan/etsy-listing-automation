# Multi-artwork listings - app-styled mockups of one design vs light/dark designs, plus per-colour designs, in the listing editor (round 3: linked pair, real editor components)

Source: docs/multi-artwork-ui.md, the approved product spec. The spec answered the discovery questions, so they weren't asked again.

- **Who:** a print-on-demand seller at a laptop, editing one listing in the listing editor.
- **One job:** pick which artwork file each shirt colour prints, and trust that previews, mockups and Printify all use that file.
- **Mode:** Operate.
- **Flow:** one design (linked pair) → unlink → fill both slots → give one colour its own design, or return it to automatic → see what blocks deploying → link again and pick which file to keep.
- **Content:** fixture listing "take-a-hike" on a garment profile with ivory, natural (light), black, moss, navy (dark) and heather (not classified).
- **Out of scope:** uploading designs, editing garment profiles, the `new` command, API wiring.
