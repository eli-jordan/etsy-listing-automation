# Design selector - four variants of a one-by-default artwork selector with drag-and-drop upload; D chosen and built (each split selector beside its own shirt, drops never split)

- **Who:** a print-on-demand seller at a laptop, editing one listing.
- **Ask:** one selector by default that applies to every shirt; a toggle to use different designs on light and dark shirts; drop a design file on the selector to upload it and select it.
- **Replaces:** the always-two-cards linked pair in the listing editor's design strip (multi-artwork board).
- **States per variant:** `one/` (default), `split/` (light + dark), `dropping/` (a file held over the selector).
- **Variants:** A switch card, B mode tabs + design rail, C compact form rows, D drop picks the scope.
- **Interactive:** every frame is live - drag a real image file from your desktop onto it, flip the toggle, pick from recent designs.
- **Out of scope:** the upload endpoint, file validation beyond "it's an image", per-colour exceptions (unchanged).
