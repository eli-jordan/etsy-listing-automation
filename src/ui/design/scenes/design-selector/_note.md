## Design selector: 4 options

Rows are states (one design / light & dark / file held over it), columns are variants A–D. Every frame works: drag an image from your desktop onto it.

| | Split control | Picking | Where you can drop |
|---|---|---|---|
| **A** switch card | switch on the card's edge | Change ▾ → recent panel | whole card, or each half |
| **B** mode + rail | One design / Light & dark tabs | recent rail always visible | tiles and the rail |
| **C** form rows | checkbox under the row | Change ▾ → recent panel | each row |
| **D** drop picks scope | text link | Change ▾ → recent panel | all / light-only / dark-only zones |

Open question: should dropping in one-design mode ever split (D), or should splitting always be a deliberate toggle (A–C)?
