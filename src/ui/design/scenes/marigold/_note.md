Selected option D is integrated across the full workflow. Mask and Unmask edit exclusions; transparent red means hidden print. Edit mask opens the floating dock; Done or Escape returns to placement. The placement box stays visible as a reference. Undo and Reset mask are in the bottom brush dock’s three-dot menu. Edit mask shows the overlay automatically; Done hides it.
