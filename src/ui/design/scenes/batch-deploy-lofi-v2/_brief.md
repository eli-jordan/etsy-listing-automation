# Batch deployment wireframes — the agreed all-listings review path, now as a clickable fake-data prototype.

Mode: Operate.

The seller starts from Listings, opens one plan across all listings, and reviews
grouped adds, updates and removals. The top of the page shows each engine stage
and how many listings will run it. Clicking a listing opens a bottom drawer with
the same per-listing stage strip and side-by-side comparison as individual
deploy. Fake apply progress advances the stage totals and finishes inline.

Out of scope: visual polish, API wiring, and changing the existing per-listing deploy flow.
