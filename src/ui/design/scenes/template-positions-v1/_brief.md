# Template positions - a listing moves, resizes or tilts the design on one mockup template, within limits (v1 snapshot: readout bar, single Settings section)

Source: docs/features/template-positions-20261102/spec.md, agreed in a design interview, so discovery questions were not asked again.

- **Who:** a print-on-demand seller at a laptop, in the listing editor's Listing Images tab.
- **One job:** make this design look right on this mockup without recalibrating the template for every listing.
- **Mode:** Operate.
- **Flow:** select a template entry → Adjust position → drag, resize, tilt (stops at the limits) → Done. Edge states: multiple-template placements, a position left outside the limits by a recalibration, a Marigold template re-preparing.
- **Content:** fixture listing night-hike-club; cc1717-folded (colour matrix), cc1717-colour-pair (multiple), cc1717-hanging-on-fence.
- **Out of scope:** Printify placement, per-colour positions, free-form corners, the calibrator's save warning.
