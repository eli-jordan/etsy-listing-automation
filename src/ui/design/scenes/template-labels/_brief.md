# Mockup template labels - free-form tags added on the workbench, and filtered from a rail search box shared with the listing (round 3, matches the spec)

- **Who:** the seller, at a laptop, tidying the library or finding a template to edit.
- **One job:** tag a template with what its photo shows, and find templates by those tags.
- **Mode:** Operate.
- **Flow:** open Mockup Templates → add label pills or type a title in the rail → open a template → add or remove its tags.
- **Content:** the 16 real templates. Photos are downscaled from the workspace; the labels on them are fixture guesses from looking at each photo.
- **Out of scope:** persistence, the API and automatic labelling. Frames hold state in memory only, and the filter is never saved.
