# Find templates on a listing - labels are pills inside the template search box, and typed text narrows them by title (round 4, matches the spec)

- **Who:** the seller, at a laptop, choosing mockups for one listing.
- **One job:** find the templates that suit this listing, then add its colours.
- **Mode:** Operate.
- **Flow:** open Listing Images → add label pills or type to narrow by title → hover to preview → open one → click colours into the gallery.
- **Search rules:** the box opens empty. A template must hold every pill and contain the typed text in its name. Typing that matches a label opens a dropdown grouped by prefix; down arrow and Enter turn it into a pill. Text matching no label stays plain text.
- **Content:** the 16 real templates and fixture tags from the template-labels scene. The listing is a made-up Christmas tee.
- **Out of scope:** persistence, the API and the Files half of the locator. Previews and gallery tiles show the ivory template photo for every colour, without the design on it.
