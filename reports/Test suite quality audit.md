# Improve confidence by simplifying the suite

The requested deliverable is the [standalone HTML audit](test-suite-audit.html):
22 impact-ranked finding groups, summary and index, primary-source examples,
actual collected counts and exploratory timings, concrete fixes and deletion
prerequisites, suite refactors, good tests, and review limits.

The largest measured feedback opportunity is compatible wheel-build reuse.
Five packaging cases totaled 192.353 seconds, equivalent to 34% of a
565.23-second hermetic run. Repair early-negative readiness and vacuous
geometry/cache/render oracles, gate real concurrency, and move narrow rule
matrices and incidental setup below full pipelines. Retain genuine provider,
HTTP/SSE, browser, filesystem, terminal, architecture, and packaging witnesses.

The exploratory hermetic run had 2,866 passes, two ambient-environment failures
and seven skips; both root-discovery failures passed with the workspace override
unset. Browser passed 97 cases. Frontend passed 997, with a 49.01-second JSON
execution envelope that is not a clean benchmark. All 62 collected real e2e
cases were source-reviewed but not executed. No coverage or mutation run was
performed. No application code or tests were changed and no deletions were
implemented.

Supporting research, run evidence and per-file inventories are linked in the
HTML. Inventories distinguish full, targeted and assertion/outline review;
they do not claim every case was individually read in full.
