# Mask controls — round two

Five new Marver alternatives after all first-round layouts were rejected. Transparent red marks the printable area. All screens show mask editing active; Done returns to placement dragging with a compact Edit mask entry point.

| Option | Arrangement | Screenshot |
| --- | --- | --- |
| A | One compact line above the image | [Single line](a-action-bar.png) |
| B | Slim vertical brush palette beside the image | [Side rail](b-editing-tabs.png) |
| C | Sentence-style action selector with secondary brush settings | [Guided brush](c-brush-menu.png) |
| D | Floating brush dock at the image's lower edge | [Floating dock](d-named-actions.png) |
| E | Context ribbon with brush actions and three size presets | [Context ribbon](e-popover-editor.png) |

Remove and Add back edit the same mask. The eye toggles its display; the three-dot menu contains Undo and Reset mask. These are local prototype interactions, with fixture mask geometry and no model inference or server writes.

Screenshots are 2560 × 2200. Option D was selected; its final wording and red-exclusion semantics are integrated into the [full workflow](../README.md). These screenshots preserve the earlier comparison. The [previous round](../controls/README.md) and its Marver scene are preserved.
