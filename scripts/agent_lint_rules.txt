# Which shell commands cannot have changed a source file (spec S06).
#
# After every shell command the agent hook first asks this
# (scripts/agent_lint_gate.py): a command that only reads is skipped at once,
# before the hook loads. Anything else falls through to the snapshot check,
# which finds what changed by content, so a command misjudged as read-only
# only delays its feedback to the next command that falls through (or to the
# pre-commit hook); nothing is lost. But a skip is the one unsafe answer: when
# unsure, leave a command out.
#
# The gate splits the line as its shell does (quotes, escapes, &&, ||, ;, |,
# a bare &, newlines) and judges every simple command in it: each segment,
# each $(...), backtick and <(...) substitution, and the script of a nested
# shell. Heredoc bodies are data and are skipped, unless their delimiter is
# unquoted and they substitute. Before a segment is matched, its leading
# VAR=value assignments and `prefix` words are dropped and its program is
# reduced to its name (`/usr/bin/git` is `git`, `C:\...\zsh.exe` is `zsh`).
# Patterns are Python regular expressions.
#
#   target <regex>             fullmatch: a redirect target that is no source
#                              file. A redirect to anything else falls through.
#                              Scratch directories can hold a checkout, so
#                              a target there must not be a source file
#                              either, nor a variable, glob or `..`.
#   variable <regex>           fullmatch on NAME=value (or NAME, for unset and
#                              a bare export): an assignment that can run a
#                              command or move a target. It falls through.
#   prefix <regex>             fullmatch on the leading words: they run the
#                              rest of the segment as it is
#   unwrap <regex>             fullmatch on the words before the last: a POSIX
#                              shell whose script is the last word
#   unwrap-powershell <regex>  the same for PowerShell, whose script is the
#                              rest of the segment
#   deny <regex>               search in a segment: it may write
#   allow <regex>              search in a segment: it only reads. Every
#                              segment must match one, and no deny.

target \$null
target (?i)nul
target (/tmp|/c/cygwin64/tmp|/cygdrive/c/cygwin64/tmp|(?i:C:[/\\]cygwin64[/\\]tmp))[/\\](?!.*\.\.)(?!.*\.(py|pyi|ts|tsx)$)[^\s$`*?\[{~]+
